# Курсы валют ЦБ РФ

Автоматическая выгрузка официальных курсов Центробанка России.

**Источник:** https://www.cbr.ru/scripts/XML_daily.asp

**Валюты:** JPY (иена), USD (доллар США), EUR (евро), CNY (юань), KRW (вон)

## Формат `rates.json`

```json
{
 "date": "24.10.2026",
 "rates": {
  "USD": 80.5381,
  "EUR": 90.2429,
  "CNY": 12.0557,
  "KRW": 0.0608018,
  "JPY": 0.514785
 }
}
```

Значения — **рублей за одну единицу валюты**. Это уже с учётом номинала,
который ЦБ публикует для KRW (за 1000) и JPY (за 100): брать поле
`VunitRate` из XML, делить вручную не нужно.

## Использование

Сайт тянет курсы напрямую:

```html
<script>
fetch("https://raw.githubusercontent.com/ramzyshef5-design/cbr-rates/main/rates.json")
  .then(r => r.json())
  .then(d => console.log(d.rates.JPY));
</script>
```

## Обновление

Файл обновляется автоматически раз в час (GitHub Actions, cron `7 * * * *`).
Вручную:

```bash
python rates.py
```

Курсы действуют с 00:00 МСК в день публикации, поэтому файл меняется
еже утром — в 07 минут первого часа.
